A production-style end-to-end data engineering platform designed to process real-time retail transaction data using Kafka, Spark, Airflow, MySQL, Python, and SQL.

### Architecture

```text
Retail Transaction Producer
          ↓
      Apache Kafka
          ↓
Spark Structured Streaming
          ↓
     Silver Layer
          ↓
      Gold Layer
          ↓
        MySQL
          ↓
 Tableau / Analytics
```

### Key Capabilities

- Generated realistic retail transaction data using Python
- Published real-time events through Apache Kafka
- Configured Kafka topic with multiple partitions
- Processed streaming data using PySpark and Spark Structured Streaming
- Built Silver-layer cleaned transaction datasets
- Created Gold-layer analytical datasets
- Developed product, category, customer, location, and daily sales summaries
- Used Apache Airflow for pipeline orchestration
- Loaded analytical outputs into MySQL
- Built analytics-ready datasets for Tableau reporting
- Used Docker and Linux for local infrastructure

### Technologies

`Python` `SQL` `Kafka` `PySpark` `Spark` `Airflow` `Docker` `MySQL`

A Python-based transaction reconciliation solution designed to validate and compare data across trading, custodian, and accounting systems.

### Architecture

```text
Trading System
      \
Custodian Data
       → Validation → Reconciliation → Exceptions
Accounting Data
      /
```

### Key Capabilities

- Processed transaction datasets from multiple financial systems
- Validated records using Pydantic
- Detected duplicate transactions
- Identified missing required fields
- Compared amount, quantity, and transaction dates
- Generated reconciliation exceptions
- Classified records into matched and unmatched groups
- Produced validation and reconciliation summaries

### Example Validation Results

- 299 combined records processed
- 296 valid records
- 99% validation pass rate
- Duplicate and missing-field detection
- Reconciliation exception categorization

### Technologies

`Python` `Pandas` `Pydantic` `Data Validation` `Reconciliation`
