## 🚀 Featured Projects

### 🛒 Real-Time Retail Data Engineering Platform

A production-style retail data platform that processes batch and streaming
transactions using Kafka, Spark and Airflow.

**Key capabilities:**

- Generated realistic retail transaction data
- Published streaming events through Apache Kafka
- Processed data using PySpark and Spark Structured Streaming
- Organized raw, silver and gold analytical datasets
- Orchestrated pipeline tasks with Apache Airflow
- Created product, category, customer, location and sales summaries
- Used Docker, MySQL, Python and SQL in the local architecture

**Technologies:** Python, SQL, Kafka, PySpark, Spark, Airflow, Docker and MySQL

[View Repository](https://github.com/Anitharaj31/retail-data-engineering-platform)
